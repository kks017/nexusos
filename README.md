Nexus OS is a small operating system that I made using HTML, CSS, and Javascript. I wanted to try to build a desktop envirnment that basically runs in the browser. The features are:

1. There is a desktop with a start menu and a taskbar.
2. There are draggable windows.
3. File explorer with folders and text files.
4. Notes which can save automatically.
5. Some basic terminal commands
6. There is a calculator which is fully functional
7. You can search for files and backup.

How do you use NexusOS?:
Open the live demo or download the code and open index.html in your browser. Files and notes are saved using localStorage, so that they stay there when you refresh the page. Other than that, have fun!
